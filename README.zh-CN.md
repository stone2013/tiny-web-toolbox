# Tiny Web Toolbox（小巧网页工具箱）

一组轻量、实用且注重隐私的网页工具，所有操作都直接在浏览器本地完成。

## 工具列表

- **进制转换器**：支持二进制、八进制、十进制和十六进制互转，也支持超大整数与负数。
- **文本工具**：转换字母大小写、清理空白和行内容、反转文本，并实时统计文本信息。
- **JSON 格式化工具**：美化、压缩并校验 JSON，提供错误位置提示。
- **颜色转换器**：支持 HEX、RGB 和 HSL 互转，提供实时颜色预览和系统取色器。
- **时间戳转换器**：转换 Unix 时间戳与本地日期，支持秒/毫秒识别、UTC、ISO 8601 和相对时间。

## 项目特点

- 无需注册账号、安装软件或后端服务，也没有外部依赖。
- 输入内容保留在你的浏览器中。
- 响应式布局，自动跟随系统切换浅色和深色主题。
- 支持英文与简体中文界面。

## 本地运行

克隆或下载本仓库，然后使用现代浏览器打开 `index.html` 即可。

## 使用 GitHub Pages 部署

进入 **Settings → Pages**，选择 **Deploy from a branch**，然后选择 `main` 分支和 `/ (root)` 目录。

## 隐私说明

所有工具都在浏览器本地处理数据，不会将用户输入发送到服务器。
