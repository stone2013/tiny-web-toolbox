# Tiny Web Toolbox

A collection of small, useful and privacy-friendly tools that run entirely in your browser.

## Tools

- **Base Converter**: convert between binary, octal, decimal and hexadecimal, including large and negative integers.
- **Text Tools**: convert letter case, clean whitespace and lines, reverse text, and view live text statistics.
- **JSON Formatter**: pretty-print, minify and validate JSON with error location details.
- **Color Converter**: convert HEX, RGB and HSL values with a live color preview and native color picker.
- **Timestamp Converter**: convert Unix timestamps and local dates, with seconds/milliseconds detection, UTC, ISO 8601 and relative time.

## Highlights

- No account, installation, backend or external dependencies.
- Your input stays in your browser.
- Responsive design and automatic system light/dark theme.
- English and Simplified Chinese interface.

## Run locally

Clone or download this repository and open `index.html` in a modern browser.

## Deploy with GitHub Pages

Open **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.

## Privacy

All tools process data locally in your browser. No user input is sent to a server.
